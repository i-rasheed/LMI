# LMI Interactive Prototype

Vanilla HTML/CSS/JS prototype of every LMI screen with dark mode.

## Open locally

```bash
open /Users/mac/Desktop/LMI/prototype/index.html
```

Or serve with any static server:

```bash
cd prototype && python3 -m http.server 8080
# Visit http://localhost:8080
```

## Features

- **62 screens** — auth, shopper, reporter, vendor, admin, settings
- **4 sheets/modals** — flag, alert, logout, badge unlock
- **Dark mode** — toggle in prototype panel or Settings → Theme
- **Role switching** — shopper, reporter, vendor, admin (changes tabs & FAB)
- **In-app navigation** — tabs, back button, CTAs, cards
- **Design system** — Content Guidelines tokens (green accent, Plus Jakarta Sans, cards, shadows)

## Prototype panel

Use the left panel to jump to any screen, switch role, toggle dark mode, or reset.
